=================================================================================

Frontend:
- React 18 con TypeScript
- Vite como bundler
- Tailwind CSS para estilos
- Componentes custom (shadcn/ui style)
- Zustand para state management
- React Router v6
- Axios con interceptores
- React Hook Form + Zod
- date-fns para fechas
- Lucide React para iconos

=================================================================================
CÓMO EMPEZAR
=================================================================================

1. npm install                    Instalar dependencias
2. npm run dev                    Iniciar servidor de desarrollo (puerto 3000)
3. npm run build                  Construir para producción
4. npm run preview                Vista previa de la build
5. npm run type-check             Validar tipos TypeScript

Variables de entorno en .env:
VITE_API_URL=http://localhost:8000
VITE_APP_NAME=Legal ERP System
